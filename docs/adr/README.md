# Architecture Decision Records (ADRs)

Numbered, dated decisions about the AdventureOrNo domain model and architecture.

The first and most important ADR — the **canonical Place / Visit / Entry / Trip
model** and the retirement of the legacy `part_of` arrays in favour of one typed
hierarchy relation — is authored in **Prompt 2A** and must be **approved by Erica
before any implementation** (Prompt 2B). Until then, the domain concepts in
[`../../README.md`](../../README.md) are the working (provisional) definitions.

Add ADRs here as `NNNN-title.md` and link them from
[`../decisions.md`](../decisions.md).
